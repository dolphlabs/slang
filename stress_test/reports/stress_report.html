The scheduler change lost. The bug it found was the win.

A full twelve-phase re-run across HTTP, raw TCP and pure concurrent-task scaling. The headline is not the feature this work set out to land — work-stealing per-worker run queues was implemented, measured across five scheduling policies, and reverted. What it exposed on the way was a heap use-after-free that had been silently corrupting shipped builds and made -O2 impossible. Fixing that, and turning optimisation on, improved almost every number below.

Work-stealing: five policies, all rejected

measured at -O2, interleaved against one baseline binary

The microbenchmark said yes: worker_fanout — a task spawned onto a worker, fanning out onto that worker's own local queue — ran ~25% faster. The HTTP harness said no, at every ordering policy tried.

policyp99 @ conc 100p99 @ conc 500
no work-stealing258–352 ms870–939 ms
local queue first249 ms3333–6202 ms
global queue first745–855 ms1208–1227 ms
rotation, global every 8th dispatch259–294 ms4102–5934 ms
global first only when non-empty755–756 ms1159–1209 ms
preempted tasks to global1896–1923 ms2628–3077 ms
Why no ordering works. The two queues hold different populations. The global queue receives everything sl_task_resume wakes — I/O completions, chan handoffs, timers — which in a server is nearly every request with a client blocked on it. The local queues receive preempted and freshly-spawned work. Any fixed priority between them starves one population, so each policy fixes one concurrency and breaks the other. Throughput was consistently +5–10%; tail latency consistently 2–7× worse. A real attempt needs fairness across the queues — sequence numbers, or a shared FIFO discipline — which is a design change, not a tuning knob.

Two hypotheses were tested and disproven, recorded so they are not retried: that the mid-concurrency cost was contention on an empty global queue (it is not — the depth-gated variant behaves identically to global-first), and that splitting by in-flight-vs-new work would unify the populations (it made both ends worse).

What actually changed

The bug

sl_chan_send and sl_chan_recv read sl_rt_current_task raw across a sl_task_park. Park is a context switch: the task resumes on whichever worker dequeues it, so a compiler that cached the thread-affine TLS address before the park then read the old worker's slot — naming whatever task that worker was running by then. A foreign, running task was enqueued on a channel wait list, later resumed while running, and finally freed with a live queue link. ASan called it a heap-use-after-free; at -O0 the window simply never opened.

Found by removing recycling from the picture — a debug build with free() as a no-op, so in-struct debug flags stayed valid. Before that, every added assertion relocated the apparent "first" fault, because it was reading recycled memory.

The unlock

With that fixed, -O2 became possible for the first time. The pre-fix build cannot run at -O2 at all: the Arcade server segfaults on startup, 100% errors, every attempt. Establishing an -O2 baseline for the tables above required backporting the fix to the old commit first.

Verification before enabling: full suite 4/4 consecutive at -O2; seven concurrency tests 0 failures in 105 runs; TSan 0 races in 48 runs where spawn raced 6/20 at -O1 beforehand; ASan+UBSan clean; and the collector's conservative stack scan exercised with a counter proving it fired 5–20 times per run rather than passing by never running.

Reading these numbers

Four raw snapshots are preserved untracked under stress_test/ so the history is auditable rather than overwritten: results_baseline_pre_O2 (Sep 2, pre-fix), results_localfirst_regression (the 4–7× regression), results_globalfirst (the partial fix), and results (shipped).

Caveat carried throughout: this machine was not idle. Load ranged from 4 to 12 during these runs, and earlier in the session an orphaned runaway process drove it to 105 — every wall-clock figure taken during that window was discarded rather than caveated. Cross-build comparisons here were re-measured interleaved, alternating order within each pair, so drift affects both sides equally. Single-cell deltas under a few percent are noise.
