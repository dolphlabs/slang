mysql

Package mysql.

Markdown version · llms.txt · api.json

A MySQL and MariaDB client over TCP, TLS or a Unix socket, with prepared statements, streamed results and a pool. The API matches pg's, so code moves between the two with little change.

import "mysql";

let cr = mysql.connect("mysql://app:secret@db.internal:3306/shop", deadline);
guard let c = cr else let e = err_of(cr) { panic(e); }

let r = mysql.query(c, "SELECT id, name, price FROM items WHERE price < ?",
                    [mysql.arg_decimal(limit)], deadline);       // result[Rows, str]
guard let rows = r else let e = err_of(r) { panic(e); }
let items: result[[Item], str] = mysql.rows_as(rows);           // by column name
mysql.get_text(rows, 0, mysql.col(rows, "name"));

let ir = mysql.query(c, "INSERT INTO items (name) VALUES (?)", [mysql.arg_text("pen")], deadline);
guard let ins = ir else let e = err_of(ir) { panic(e); }
ins.last_insert_id;                                              // the AUTO_INCREMENT value

mysql.exec(c, "BEGIN; UPDATE stock SET n = n - 1 WHERE id = 7; COMMIT", deadline);   // several statements

let pr = mysql.new_pool(url, 16);                                // shared by any number of tasks
guard let p = pr else let e = err_of(pr) { panic(e); }
mysql.pool_query(p, "SELECT 1", [], deadline);

query and exec. query runs one statement with ? parameters, as a server-side prepared statement cached per connection (256 by default, statement_cache=N), so parameter values never pass through the SQL text. It returns the rows, or for an INSERT or UPDATE an empty result whose affected and last_insert_id say what it did. exec sends text and runs any number of statements: migrations, schema, BEGIN … COMMIT.

Results read like pg's: col, is_null, get_text, get_int, get_float, get_bool (tinyint(1)), get_bytes (BLOB and BINARY, NULs intact), get_time (DATETIME, TIMESTAMP and DATE, read as UTC), get_decimal (exact), and rows_as[T], which binds by column name through the same compiled decoder as pg.rows_as. Values past 2^63 in a BIGINT UNSIGNED arrive exactly as text. stream with next_row reads a large result one row at a time. A result held whole is bounded at 256 MiB.

Connecting. sslmode=require (the default except for loopback hosts and Unix sockets) means TLS with the certificate and host name verified; sslrootcert= names a CA bundle. prefer is refused, because falling back to cleartext is what an attacker in the middle arranges. Supported authentication:

  • mysql_native_password (MariaDB's default)
  • caching_sha2_password (MySQL 8's default)
  • sha256_password
  • mysql_clear_password (over TLS only)
  • switching between them when the server asks

When caching_sha2_password needs the password itself, it goes over TLS or a Unix socket. Without either, it is encrypted with RSA-OAEP to server_public_key=/path/key.pem. Fetching the key from the server is only done with allow_public_key_retrieval=true, since on an unencrypted connection anyone in the middle can send their own key. time_zone=+00:00 sets the session time zone after connecting.

Failures. Errors read mysql: ERROR 1062 (23000): Duplicate entry …; mysql.error_code(e) and mysql.sqlstate(e) take them apart. A server error leaves the connection usable. A timeout or I/O error breaks it, and after a timeout the statement is killed from a second connection (KILL QUERY), so it does not run on. The server is never sent a local file (LOAD DATA LOCAL is not offered).

Cost. Cells live in the connection's receive buffers, a handful of objects per result, and binary-protocol numbers and dates are written into one more. Against a MySQL 8.4 container, 100,000 rows of three columns buffer in about 130 ms. A point query takes about 0.35 ms, which is Docker's network round trip: a bare mysql.ping costs the same.

fn parse_url(url: str) -> result[Config, str] stdlib/mysql/mysql.sl:106#

mysql://user:password@host:port/database?sslmode=require Parameters: sslmode (disable, require; verify-full is require), sslrootcert (a CA bundle), server_public_key (a PEM file), allow_public_key_retrieval (true), time_zone (e.g. +00:00), statement_cache (0 to 65536). Any other parameter is an error: a misspelt sslmode silently dropped would connect in the clear. TLS is required by default, except to a loopback host or over a Unix socket (host=/path/to/mysqld.sock, or the path percent-encoded as the host), where it is off.

fn acquire(p: Pool, deadline: until) -> result[Conn, str] stdlib/mysql/pool.sl:188#

A connection for the caller's exclusive use, until release(). Prefer pool_query / pool_exec, which cannot forget to release; acquire is for a transaction, which needs several statements on one connection.

fn release(p: Pool, c: Conn) stdlib/mysql/pool.sl:264#

Returns a connection to the pool: to the oldest waiting task if there is one, else to the idle list. One that is broken, closed, or still inside a transaction is closed instead, and its slot passed on: handing an open transaction to the next caller would run its statements inside someone else's uncommitted work.

gc struct Rows stdlib/mysql/rows.sl:113#

A buffered result. Cells live in a few chunks -- the connection's own receive buffers, plus one for values the binary protocol sends as numbers -- rather than one object per cell, so a large result costs the collector a handful of objects. types are Postgres-style codes (see mysql_code), which is what lets rows_as share pg's compiled decoder.
