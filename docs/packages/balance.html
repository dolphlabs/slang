balance

Package balance.

Markdown·llms.txt·api.json

Client-side load balancing: pick a backend per request, spread load, steer away from slow backends and stop sending to failing ones.

slang
import "balance";
import "time";

let lb = balance.new(["10.0.0.1:8080", "10.0.0.2:8080"], balance.P2C);
let pr = balance.pick(lb, "");
guard let p = pr else { return err("no backend up"); }
let t0 = time.mono();
let r = call(p.addr);
let worked = false;
if let _v = r { worked = true; }
balance.done(lb, p, worked, (time.mono() - t0) as int);
StrategyPicks
ROUND_ROBINeach backend in turn
RANDOMuniformly at random
LEASTthe fewest requests in flight
P2Ctwo at random, the one with fewer in flight, then the lower latency (an EWMA): nearly LEAST's spread without herding every client onto one backend
HASHthe backend a key maps to (rendezvous hashing via math/shard), and the key's next backend while that one is ejected

A backend that fails eject_after times in a row (5) is ejected for eject_ns (10 s), doubling for each ejection in a row up to eject_max_ns (5 minutes); a success resets it. set_backends replaces the list from service discovery and keeps the state of backends that stay. status reports each backend.
