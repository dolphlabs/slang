context

Package context.

Markdown·llms.txt·api.json

Cancellation and deadlines that flow from a request through everything it starts, so one timeout or one cancel stops all the work under it.

slang
import "context";
import "net";

let req = context.with_timeout(context.background(), 2000000000);  // 2 s
let db = context.with_cancel(req);          // ends when req ends
context.watch_fd(db, fd);                   // a cancel closes fd
let rr = net.recv_until(fd, 4096, context.deadline(db));
context.cancel(req, "client went away");    // ends req and db
println(context.cause(db) ?? "live");       // "client went away"
context.release(db);
  • background() is the root. with_cancel(parent), with_timeout(parent, ns) and with_deadline_at(parent, mono_ns) make children; a child's deadline is the earlier of its own and its parent's, and cancelling a context cancels everything made from it.
  • deadline(c) is an until for any API that waits; remaining(c) is the nanoseconds left (-1 without a deadline), for a timeout another protocol carries.
  • cancel(c, reason) (the first reason wins) and release(c), for a context whose work is done. Call one of them, as with Go's contexts: until then a child stays in its parent's list.
  • is_done(c) and cause(c): the cancel reason, "deadline exceeded", or none while live.
  • watch_fd(c, fd) closes fd on cancel, waking a task parked on it with "closed"; unwatch_fd before closing it yourself. done_chan(c) is closed on cancel, for a select.

There are no timers: a deadline passing does not close watched fds. The operations given deadline(c) end at it on their own.

fn deadline(c: Context) -> until stdlib/context/context.sl:136#

c's deadline as an until for any API that waits: never for a context without one, already passed for a cancelled one.

fn remaining(c: Context) -> int stdlib/context/context.sl:153#

Nanoseconds until c's deadline (0 once passed or cancelled), or -1 for a context without one: for a timeout another protocol carries, such as a database statement timeout.

fn watch_fd(c: Context, fd: i32) stdlib/context/context.sl:175#

Closes fd when c is cancelled, waking any task parked on it with "closed". If c is already cancelled, closes it now. Call unwatch_fd before closing fd yourself, so a later cancel cannot close a reused fd number.

fn unwatch_fd(c: Context, fd: i32) -> bool stdlib/context/context.sl:188#

Stops watching fd. Returns false if c had already been cancelled (and fd closed by it).

fn done_chan(c: Context) -> chan[bool] stdlib/context/context.sl:207#

A channel that is closed when c is cancelled, for a select that should also end on cancellation. Nothing is ever sent on it.
