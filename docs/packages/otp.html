otp

Package otp.

Markdown·llms.txt·api.json

One-time passwords for two-factor sign-in: HOTP (RFC 4226) and TOTP (RFC 6238), the codes authenticator apps show.

slang
import "otp";

// enrolment: keep the secret, show the URI as a QR code
let secret = otp.new_secret() ?? b"";
let uri = otp.uri(secret, "Acme", "ada@example.com", otp.totp_options());

// sign-in: accept each code once
let matched = otp.verify_totp(secret, code, now_unix_secs, otp.totp_options());
guard let step = matched else { return deny(); }
if step <= user.last_otp_step { return deny(); }   // a replay
user.last_otp_step = step;

totp_options() gives 6 digits, 30-second steps, one step of skew either side, and SHA-1 (what apps assume; "SHA256" and "SHA512" also work). verify_totp compares in constant time and returns the time step that matched, so a code cannot be used twice: within its 30 seconds it is otherwise valid for anyone who saw it. There are also hotp, totp, verify_hotp (with a look-ahead window), parse_secret (base32 as apps show it) and new_secret (160 random bits). Checked against both RFCs' test vectors.
