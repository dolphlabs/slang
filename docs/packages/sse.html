sse

Package sse.

Markdown·llms.txt·api.json

Server-Sent Events: a server pushing events to a browser's EventSource over one long response, and a client reading such a stream.

slang
import "sse";

// server, on a link after reading the request
c.send_bytes(sse.head(), deadline);
c.send_bytes(sse.event("tick", "{\"n\":1}", "1"), deadline);
c.send_bytes(sse.comment("keep-alive"), deadline);     // every ~15 seconds

// client
let p = sse.parser();
for e in sse.feed(p, chunk) { println(e.kind + ": " + e.data); }

head() sends no Content-Length (the stream ends when the server closes the connection) and tells buffering proxies not to hold events back. event splits multi-line data into data lines. The parser follows the HTML specification: CR, LF and CRLF line endings even when split between chunks, the last event id (for Last-Event-ID on reconnect), retry_ms, comments, and a leading byte-order mark.
