metrics

Package metrics.

Markdown·llms.txt·api.json

Prometheus metrics: counters, gauges and histograms with labels, and the text exposition format a Prometheus server scrapes.

slang
import "metrics";

let reg = metrics.registry();
let reqs = metrics.counter(reg, "http_requests_total", "Requests served.",
                           ["method", "code"]);
let lat = metrics.histogram(reg, "http_request_duration_seconds",
                            "Request latency.", ["route"],
                            metrics.default_buckets());

metrics.inc(metrics.with(reqs, ["GET", "200"]));
let users = metrics.with(lat, ["/users"]);   // keep it: no lookup per update
metrics.observe(users, 0.012);

// GET /metrics: answer metrics.expose(reg), Content-Type metrics.CONTENT_TYPE
  • counter (inc, add; a decrease panics), gauge (set, add, inc, dec) and histogram (observe) register a family by name; with(family, label_values) gives a series. Keeping the series makes an update one lock, with no label lookup. remove drops a series whose label value will not come back, so memory does not grow without bound.
  • Histograms are classic fixed-bucket ones, which Prometheus scrapes: a few ints a series and a binary search per observation. default_buckets() are Prometheus's latency buckets in seconds; exponential_buckets(start, factor, count) makes others.
  • expose(reg) sorts families and series, so two scrapes of an idle program are identical. Names and label names are checked at registration, and label values and help text are escaped.
