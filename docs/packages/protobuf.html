protobuf

Package protobuf.

Markdown·llms.txt·api.json

The Protocol Buffers wire format, written and read field by field without generated code: for talking to a gRPC or protobuf service whose messages are few, or for building a codec on top.

slang
import "protobuf";

// message User { int64 id = 1; string name = 2; repeated sint32 deltas = 3; }
let w = protobuf.writer();
protobuf.write_int64(w, 1, 42);
protobuf.write_string(w, 2, "ada");
protobuf.write_packed_sint(w, 3, [-1, 5, -9]);
let data = protobuf.finish(w);

let r = protobuf.reader(data);
while protobuf.more(r) {
    let fr = protobuf.next(r);              // field number and wire type
    guard let f = fr else { break; }
    if f.num == 2 {
        name = protobuf.read_string(r) ?? "";
    } else {
        protobuf.skip(r, f.wire);           // a field this reader does not use
    }
}

There are writers for every scalar type (write_int64, write_uint64, write_sint with zigzag, write_bool, write_fixed64, write_fixed32, write_double, write_float), plus write_bytes, write_string and packed repeated fields. A nested message is its own Writer, passed to write_bytes. The readers mirror them; read_packed_* also accept an unpacked element, as parsers must. Lengths are checked against the input and varints against their ten-byte limit. Groups (wire types 3 and 4) are not read.
