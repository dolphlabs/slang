Build it in slang with the zokor framework. Read these two first; they are
written for you and are short:

- slang, the whole language on one page:
  https://slang.dolphlabs.com/llms-small.txt
- zokor, how a service is built with it:
  https://raw.githubusercontent.com/dolphlabs/zokor/main/docs/llms-small.txt

Pin zokor in `slang.project` as zokor's README shows and run `slangc get`.
`slangc doc <pkg>` prints a package's API; `slangc doc <pkg>.<name>` one item.
